# human-ui-ux

Inspect existing screens and user tasks before editing. Keep the current React/Vite stack and shared components. Use restrained amber accents, neutral surfaces, readable type, consistent spacing and clear primary actions. Prefer static timelines, tables and meaningful charts to decorative 3D, audio, glow or motion. Respect reduced motion. Use role-specific navigation, progressive disclosure, keyboard focus, semantic labels, contrast and mobile layouts. Show loading, empty, error and success states. Never invent metrics or verification badges. Run the app and inspect desktop and mobile screenshots; test keyboard navigation and forms. Use axe if available; report untested screens.
