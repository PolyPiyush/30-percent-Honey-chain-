# automated-testing

Inspect package scripts and existing test infrastructure; add compatible Vitest, Supertest or Playwright only when needed. Test happy paths and invalid inputs, permission failures, network errors, empty states and mobile navigation. Cover hive readings, harvest, batch creation, processing, quality, custody, QR and public verification. Use isolated fixtures and disposable storage; never mutate production. Mock external services explicitly and separately test real integrations when configured. Run typecheck, build and tests; report counts and failures from actual output.
